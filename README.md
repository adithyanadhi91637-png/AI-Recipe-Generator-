AI RECIPE GENERATOR & FOOD WASTE REDUCTION SYSTEM

An AI-powered recipe recommendation web application built with Flask, Python, and MySQL that suggests delicious recipes based on the ingredients available in your kitchen.
The application helps reduce food waste by recommending recipes using ingredients users already have.

---

# Features

- User Registration & Login System
- AI-Based Recipe Recommendation
- Ingredient-Based Recipe Search
- Detailed Recipe View
- Search History for Logged-in Users
- 20+ Built-in Recipes
- Responsive & Modern User Interface
- MySQL Database Integration

# How It Works

1. User creates an account or logs in.
2. User enters available kitchen ingredients.
3. The AI recommendation engine compares the ingredients with stored recipes.
4. Matching recipes are displayed based on available ingredients.
5. Users can view complete recipe details.
6. Logged-in users can view their previous searches.
